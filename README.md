# selector_fecha_hora

Este componente es un selector interactivo de fecha y hora desarrollado con HTML, CSS, JavaScript y Bootstrap 4. Permite a los usuarios elegir de forma intuitiva una fecha específica desde un calendario visual, así como seleccionar una hora mediante un campo de entrada tipo time.

## Características destacadas:

📅 Calendario dinámico con navegación entre meses mediante botones.  
✅ Selección visual de día, con marcado del día actual y del día elegido.  
🕓 Campo de hora personalizable, con valor predeterminado ajustable.  
📝 Visualización clara de la fecha seleccionada, sin permitir edición manual directa.  
🎯 Botones de acción personalizables para confirmar o cancelar la selección.  
💡 Compatible con dispositivos móviles gracias a Bootstrap y diseño responsivo.

---

Este componente es ideal para integrarlo en sistemas de reservas, planificación de eventos, programaciones de envío de correos o cualquier aplicación donde se requiera que el usuario seleccione una fecha y hora específicas.
